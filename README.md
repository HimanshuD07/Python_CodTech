# Task 4: Machine Learning Model Implementation

## Overview
This repository contains the solution for **Task 4** of the CODTECH IT Solutions Python Internship. The objective of this project is to engineer a supervised machine learning pipeline using `scikit-learn` to classify text data. Specifically, it implements a binary classification model to detect Spam vs. Ham emails.

---

## Features
* **End-to-End ML Pipeline:** Encapsulates data preprocessing, feature extraction (Bag-of-Words), and model training within a unified `sklearn.pipeline.Pipeline` to prevent data leakage.
* **Algorithmic Modeling:** Utilizes a `RandomForestClassifier` to handle the high-dimensional sparse matrices generated by text data.
* **Robust Evaluation:** Employs Stratified K-Fold Cross-Validation to ensure unbiased scoring, alongside a comprehensive evaluation suite computing Precision, Recall, F1-Score, and a Confusion Matrix.
* **Interpretability:** Extracts and visualizes Gini feature importances to highlight the exact vocabulary tokens that trigger spam classifications.
